# Jakarta Inject

[English](README.md) | [简体中文](README.zh-CN.md)

The adapter declaration and runnable example are in `jakarta/inject`. It pins Jakarta Inject 2.0.1 and defines its package coordinates in [module.norm](jakarta/inject/module.norm). The public API covers injection, scopes, qualifiers, names, and the Provider API.
